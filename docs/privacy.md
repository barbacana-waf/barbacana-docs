# Privacy

This site measures which pages are read and for how long, to improve the documentation.
It uses no cookies and does not store IP addresses. For each page view it records the page,
the referring site, your browser's user agent, how long the page was visible, and how far
you scrolled. The site also uses Cloudflare Web Analytics to count page views.

Cloudflare hosts both services and receives your IP address while it handles the requests.
We do not read or store it.

Your browser's Do Not Track setting is respected.

Questions: open an issue in the [documentation repository](https://github.com/barbacana-waf/barbacana-docs/issues).
